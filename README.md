# Event Ticket Booking System

A responsive front-end web application built for booking event tickets seamlessly across all devices.

## 🚀 Features
- **Featured Events:** Browse through concerts, movies, and sports events with details like venue, date, and price.
- **Interactive Booking:** Click-to-select event functionality with smooth scrolling to the booking section.
- **Form Validation:** Client-side validation ensuring all necessary fields and valid email addresses are entered before confirmation.
- **Responsive Design:** Optimized layout for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox & Media Queries)
- JavaScript (DOM Manipulation & Validation)
